Windows Quick Start

1) Install Node.js LTS from nodejs.org and restart your PC.
2) Double-click "Start Bot.bat" in this folder.
3) Your browser opens http://localhost:5173
4) In the app:
   - Exchange Connection: select exchange, paste API keys (and passphrase if Bitget), click Connect
   - Enable "Enable Real Trading" and "Enable Futures"
   - Set only: Invest per trade ($) and Profit goal ($)
   - Click Start

Notes:
- Leave the console windows running; the UI is in your browser.
- To stop, close the console windows or click Stop in the UI.
- Keys are used locally via the built-in backend (server/).
